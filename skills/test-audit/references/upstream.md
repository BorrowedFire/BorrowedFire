# Upstream source and license

This skill adapts the authoring questions, candidate patterns, retention criteria, evidence
ledger, and campaign preservation checks from OpenClaw at commit
`daecbc5cf54c6301a2292ca7ad88cecc51a119af`:

- [Test audit](https://github.com/openclaw/openclaw/blob/daecbc5cf54c6301a2292ca7ad88cecc51a119af/.agents/skills/test-audit/SKILL.md)
- [Campaign guide](https://github.com/openclaw/openclaw/blob/daecbc5cf54c6301a2292ca7ad88cecc51a119af/.agents/skills/test-audit/CAMPAIGN.md)
- [License](https://github.com/openclaw/openclaw/blob/daecbc5cf54c6301a2292ca7ad88cecc51a119af/LICENSE)

Borrowed Fire adds a self-contained doctrine rule, portable commands, existing workflow gates,
coverage comparison rules, and a campaign target with an evidence-based stopping condition.
It retains useful test seams and independent text contracts.
